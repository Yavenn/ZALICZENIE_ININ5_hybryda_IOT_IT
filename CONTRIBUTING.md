# Wkład w projekt

Dziękujemy za chęć współpracy! Poniżej znajdują się zasady obowiązujące osoby dołączające do projektu.

## Zasady tworzenia branchy
- Każdy branch powinien być tworzony według schematu: `stolica-nazwisko_imie`
- Branch tworzony z `main`

## Zasady commitów
- Każdy commit powinien mieć opis w języku polskim lub angielskim
- Przykładowe wiadomości commitów:
  - `Dodano sekcję HTML dla stolicy Zagrzeb`
  - `Poprawiono styl CSS dla tabeli`
  - `Aktualizacja README.md`

## Współpraca i komunikacja
- Komunikacja odbywa się przez komentarze w Pull Requestach oraz Trello
- Każdy pull request powinien zawierać opis wprowadzonych zmian
- W Trello należy oznaczać postęp prac w kolumnach: To Do / In Progress / Done
