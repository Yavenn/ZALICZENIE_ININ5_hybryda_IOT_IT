# Projekt Zaliczeniowy – ININ5 Hybryda IoT/IT

## Opis projektu
Celem projektu jest wykonanie strony internetowej prezez informacjami o stolicach państw w ramach zadania zaliczeniowego przedmiotu Projekt Wdrozeniowy. Projekt powstaje w oparciu o repozytorium prowadzącego i zawiera dodatkowe materiały graficzne oraz sekcje HTML z opisem stolic.

## Wykorzystane technologie
- HTML5
- CSS3
- Git / GitHub do kontroli wersji
- Trello
